General notes

  1. C from the equipment transformer is system ground. Tie C, buck output −, ESP32 GND and all sensor grounds together.
  2. Set each LM2596HV to 5.00 V with a meter before connecting the ESP32 or sensors.
  3. Never have USB and 24 VAC connected at the same time while flashing.
  4. All 0.1 µF filter capacitors mount directly at the ADS1115 input pins.
  5. Mount the ESP32 in a plastic enclosure outside sheet-metal cabinets so the PCB antenna can reach WiFi.
