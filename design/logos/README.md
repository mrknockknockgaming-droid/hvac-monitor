# Logos

- `fullscope-lockup.png` — full lockup on its original black: reticle, wordmark and the tagline "CONTINUOUS DIAGNOSTICS & CONTROL". Use at 240px wide or more.
- `fullscope-lockup-transparent.png` — the same with the black keyed out to transparency (glow preserved).
- `fullscope-wordmark.png` / `fullscope-wordmark-transparent.png` — reticle and wordmark without the tagline, for headers and footers; pair with the tagline set as text.

The artwork is light chrome and green glow, so the transparent files only work on dark grounds (`bar-bg`, the dark theme). On white or light grey use the black originals. Ask the designer for vector (SVG) masters before production.
